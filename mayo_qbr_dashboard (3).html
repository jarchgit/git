Design decisions

Numbered pins on the dashboard match these notes.

  1. 1
    Verdict first, as a 3-position scaleOne amber badge, one sentence of cause, and a Behind / On plan / Ahead strip with the marker lit. A gauge would spend space on false precision; the leadership question is categorical. The signal uses icon + word + colour, never colour alone.
  2. 2
    Phase banners as chevrons in sequenceCrawl → Walk → Run keeps the roadmap's dependency order visible. Each banner carries a status chip and a one-line "read", so the phase answer is available without opening a metric.
  3. 3
    Bullet bar on a shared attainment axisThe seven metrics use seven units (millions, months, counts, %). Converting each to attainment (current ÷ target) puts them on one 0–120% axis, with threshold bands behind the bar and a tick at the target. Chosen over gauges and donuts, which take more space and compare badly.
  4. 3b
    Sparkline on a true time axisPublic data arrives irregularly, so points are spaced by date, not evenly. That makes the Connect plateau (2 → 5 → 8 → 8 members) visible. Solid line = reported; dashed = illustrative. A line connects reported points only; it is not an interpolation of the gaps.
  5. 4
    Evidence grade on every cardREPORTED (a published figure), DERIVED (computed from published dates or lists) or ILLUSTRATIVE (no public data). Targets are always illustrative because Mayo publishes none, so status means "reported actual vs our assumed target".
  6. 5
    Handoff panel: what is publishedScale figures from Mayo's public record, so the Walk-to-Run story rests on them. The Run metrics that lack public data are marked illustrative in their cards.
  7. 6
    Decisions as cards, not a tableEach card holds the question, evidence chips tied by ID to the metrics above, two options with a recommendation, the RACI roles, and a deadline. Taken from D1–D7 in the RACI, not new ones.
  8. 7
    Ordered by dependencyD6 shortens onboarding, which frees D4's capacity call, which sets up D7's go-live gate. D7 recommends A because the RACI rationale puts patient safety ahead of speed to the point of care.
Not shown: qualification pass rate and outcome change per solution (no public data), and cloud cost (undisclosed). Colours: one blue for all bars; status colours are reserved for status; text uses ink, never status hue.
